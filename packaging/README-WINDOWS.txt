OrcaSlicer Matrix Studio v2.0.1 - Windows x64
================================================

These are portable applications. No Python installation or compiler is needed.

INTEGRATED ORCASLICER PACKAGE (recommended)
--------------------------------------------
1. Extract the entire ZIP to a normal writable folder.
2. Run orca-slicer.exe.
3. Load a model and use the Matrix Studio item in OrcaSlicer's menu.

Keep the tools\OrcaMatrix folder beside orca-slicer.exe. Moving only the EXE
will break Matrix Studio discovery and may also break OrcaSlicer resources.

STANDALONE MATRIX STUDIO PACKAGE
--------------------------------
1. Extract the entire ZIP.
2. Run OrcaMatrixStudio.exe.
3. Connect it to a running Matrix Studio-enabled OrcaSlicer instance.

The standalone package does not replace OrcaSlicer; slicing and synchronized
Compare View require the compatible custom OrcaSlicer build.

WINDOWS SECURITY NOTE
---------------------
These community builds are not code-signed. Windows SmartScreen may display an
Unknown Publisher warning. Verify the SHA-256 checksum from SHA256SUMS.txt before
running the files. Do not download release binaries from third-party mirrors.
